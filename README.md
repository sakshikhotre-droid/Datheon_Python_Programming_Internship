
# Hangman Word Guessing Game

## About Project
This is a Python-based console Hangman
Word Guessing Game.

## Features
- Random word selection
- Letter guessing system
- Limited attempts
- Win and lose conditions
- Play again option
- Input validation

## Technology Used
- Python 3
- Random Module

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Run python hangman.py.
